# HNDIT Learning Lab

A practical learning repository for my HNDIT studies: small, complete projects built while practicing web development, programming fundamentals, and C#.

The older coursework files are still kept in the repository. Newer work is organized under `projects/` and `lessons/` so the repo is easier to browse and actually useful as a learning archive.

## Running the projects

Web projects are dependency-free: open their `index.html` file in a browser.

For C# projects, open a terminal in the project folder and run:

```bash
dotnet run
```

## Why this repo exists

This is not meant to pretend every exercise is a production product. It is a visible record of learning through finished, runnable work rather than only notes or screenshots.
