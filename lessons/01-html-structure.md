# HTML structure

## The basic document

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page title</title>
</head>
<body>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</body>
</html>
```

## Useful rules

- Use semantic elements when they describe the content: `header`, `nav`, `main`, `section`, `article`, `footer`.
- Every form control should have a label.
- Buttons perform actions; links navigate somewhere.
- Keep heading levels meaningful instead of choosing them for size.
- Add `alt` text to informative images.
